## 实际发现与修复

- 正式入口遇到广告、可选保活／辅助模式提示及安全提示。精确／后台定位已授权，
  使用客户端提供的保持前台选项进入准备页；没有额外开启辅助服务或修改目标APK。
- 原GPS位置与本机路线起点相距约862米。未开始时用官方模拟器定位工具设置起点，
  系统GPS实收误差2.37米，原App保持0公里／0秒，GPS文案为`GPS信号优`。
- `StartConnector`在实际App一次点击开始后获取独立的递增计时两帧，实际
  `StartWitness`校验通过。短位置线程输出使待分配距离减少，但这不是有效成绩。
- 原串行查询无法及时续约，5秒片段发送63行后安全停止。将焦点＋版本前查询、
  焦点＋Android时钟＋自有运动状态后查询合为各一次受设备守卫的只读批次。
  已连接UI的实测每帧约0.63–0.65秒；初次UI连接仍更慢，不能据此承诺每帧固定耗时。
- 新独立UID接收服务在后台限时采集，原App保持前台。暂停状态5秒实测两类原始
  传感器各251行完整接收，约49.53Hz，检查后恢复NORMAL模式。
- 联合GPS输出时，位置IO锁可能延迟运动续期：先续位置的10秒实测在450／501行
  到期停止。改为**先运动续期，再进入位置IO**后，两类各501行完整独立UID接收，
  约49.35Hz，GPS同时发出10个已确认命令；原App实际里程显示0.04公里。
  两秒租约及运动观察一秒最大年龄没有放宽。

`RuntimeDispatcher.update(frame, renew_motion=...)`支持同帧运动续期回调，
在真实开始、明确运行及卡片观察允许移动之后、位置锁操作之前调用。
未知／暂停／本人验证时不调用；失败撤销位置输出。调用方仍负责停止运动服务、
恢复模式、持有实际会话证据，不能凭此参数接管任意旧会话。

## 可重复的诊断入口

只在本项目模拟器的原App**明确暂停页**使用；运行页、倒计时和其它页面拒绝。
必须事先安装新版本独立接收APK，运行后台监听服务不会切换原App前台。

```powershell
uv run budao probe-mumu-target-motion --seconds 5 --output .local/runs/target-motion-new.json
```

结果保存到私有独占文件；完整原始样本、实际路线和截图不入仓库。
接收服务最多15秒、8192事件，DUMP权限保护，非sticky；不联网、不定位、不注入，
不生成标准计步事件。输入服务仍限1–10秒有来源片段和两秒逐帧许可。
